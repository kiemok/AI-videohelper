============================================================
基于B站与抖音的多源数据融合及AI驱动的内容创作决策系统
功能与用途说明（v0.1.0）
============================================================

一、这是什么
一个面向短视频创作者的桌面端智能助手：把 B站 和 抖音 两个平台的数据统一采集、
在本地完成分析，再调用大模型生成通俗的数据解读与创作建议，全部在一个桌面软件里完成。

二、主要功能
1. 数据采集与融合
   抓取 B站/抖音 指定 UP主、关键词或热门榜单的作品与评论数据，
   把两个平台不同的字段统一成一套数据模型后存入本地数据库。
   （爬虫模块已预留接口，当前版本使用离线样例数据）

2. 数据存储与管理
   本地数据库保存账号、作品、每日指标快照、评论、分析结果与 AI 报告；
   默认 SQLite 单文件零配置，可一行切换 MySQL；支持 CSV 导入导出与快照归档。

3. 本地数据分析
   计算播放增量、互动率、增长率、传播健康度等指标；
   自动检测数据异常拐点（突然放量 / 传播衰减）；分析评论区情感倾向与热词。

4. AI 解读与建议
   把分析结果交给大模型（DeepSeek / 通义千问，API Key 由用户填写且只保存在本机），
   生成数据简报、选题建议、标题优化、发布时间建议；
   未配置 Key 时自动改用本地规则生成，功能不受影响。

5. 可视化看板
   双平台对比图、近 30 天趋势图、KPI 卡片、作品排行榜、评论情感分布、热词词云。

6. 交互问答
   用自然语言提问（例如"抖音和B站哪个平台互动更好"），
   系统结合当前数据上下文给出回答。

7. 定时任务
   可设置每天固定时间自动执行一次分析。

三、用途
1. 帮助创作者快速看懂双平台数据表现，判断哪条内容值得复用、哪个平台该加码。
2. 用数据回答"下一条拍什么、标题怎么写、什么时间发布"等实际决策问题。
3. 作为毕业设计：演示「数据采集 → 融合存储 → 本地分析 → 大模型解读 → 可视化呈现」
   的完整技术链路。

四、使用方法
1. 启动程序：python -m app.main
2. 进入"数据管理"页，点击"同步样例数据"（爬虫接入后即为真实数据）
3. 点击"执行分析"，然后在 数据看板 / 分析详情 / AI 助手 页查看结果
4. 想获得真实 AI 解读：在"设置"页填入自己的大模型 API Key 并保存

五、技术要点
界面与调度：Python + PySide6（含 QtCharts 图表）
数据存储：SQLAlchemy 统一数据模型（SQLite 默认 / 可切 MySQL）
数据处理：Pandas、NumPy
大模型：requests 调用 OpenAI 兼容接口（DeepSeek / 通义千问）
任务调度：APScheduler
说明：所有数据和 API Key 都保存在用户本机，不上传服务器。
